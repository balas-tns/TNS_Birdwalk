Local bird names for spoken mode
================================
te.csv = Telugu, hi.csv = Hindi, ta.csv = Tamil.

Columns: sci_name, english_name, local_name
- The app matches birds by sci_name (exactly as BirdNET spells it).
- Fill in local_name in that language's script. Leave it blank and the app says the English name.
- Add a new row for any species. The rows can be in any order.
- Don't use commas inside a name.

A few common names are already filled in. Ask TNS members to check them, then add the
local names they use around Tirupati. Open these files in Excel or Google Sheets,
save as CSV (UTF-8), and upload them to the names folder on GitHub.
